# أذكار وأدعية حسب شعورك

Arabic-first Next.js application that helps people find duas and adhkar related
to how they feel. The interface uses a butter-yellow (`#FEEB9C`) and lavender
(`#CBA1D4`) palette and supports search, local bookmarks, sharing, source links,
and statically generated feeling pages.

## Technology

- Next.js 16 App Router and React 19
- TypeScript and Tailwind CSS
- Static JSON datasets generated by the companion Python scraper
- Browser `localStorage` for private, device-local bookmarks

## Local development

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Quality checks

```bash
npm run check
npm run build
npm audit
```

`npm run check` runs TypeScript, ESLint, and dataset tests. CI runs the same
checks and a production build for pushes and pull requests.

## Data flow

```text
allahuakbarofficial.com
  -> dua_scraper/scraper.py
  -> dua_scraper/output/*.json
  -> dua_scraper/sync_frontend_data.py
  -> src/data/*.json
  -> server-side data helpers
  -> compact normalized search props / static feeling pages
```

Run the scraper only after reviewing the source website's access policies. See
[`dua_scraper/README.md`](dua_scraper/README.md) for setup and usage. After a
successful scrape, validate and sync the output:

```bash
python dua_scraper/sync_frontend_data.py
npm test
```

## Editorial and safety notes

- Arabic display titles live in `src/data/dua_titles_ar.json` as exact reviewed
  entries. Runtime partial translation is intentionally not used.
- Scraped religious text and citations still require qualified human review
  before being described as authoritative.
- The high-risk feeling page includes urgent-help guidance. Spiritual material
  is presented as complementary support, not a substitute for emergency,
  medical, or mental-health care.
- Bookmarks never leave the user's browser.

## Repository hygiene

Generated `.next` and TypeScript build artifacts are ignored. Older commits
contain historical `.next` cache objects; removing those requires a coordinated
history rewrite and force-push, so it is intentionally not automated here.
